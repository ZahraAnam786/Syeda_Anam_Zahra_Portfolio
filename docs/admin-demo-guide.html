Portfolio Admin: Demo Guide

How to add a project to your portfolio from admin.html, and what to write in each field.

Add a project in 6 steps

  1. Open admin.html on your live site and connect with your GitHub token (one time).
  2. Click New project.
  3. Fill the top fields: name, short description, technologies, links and card colour.
  4. Fill the sections. Each section is one part of the project page. Add blocks inside it: Text, Highlights, Screenshots or Table.
  5. Click Preview to see the home page card and the project page.
  6. Click Publish. The site updates in about 1 to 2 minutes.
Good to know: the project at the top of the list is shown as the big “Latest project” panel on the home page. Use the up and down buttons in “Your projects” to change the order. The first screenshot of a project is the cover picture.
