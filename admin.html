How do I get a token? (one time, 2 minutes)
  1. Open github.com/settings/personal-access-tokens/new.
  2. Name: portfolio-admin. Expiration: pick 90 days or more.
  3. Repository access: Only select repositories, then choose this portfolio repository.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Click Generate token, copy it and paste it above. Never share it with anyone.
